This panel can be resized. but only in the vertical dimension. It's bundle configuration looks like: 

    {
      "file": "sizing/sizing_one.html",
      "name": "sizing-one",
      "title": "Vertical Change Only",
      "workspace": "Sizing",
      "size": {
        "width": 6,
        "height": 6
      },
      "minSize": {
        "width": 6,
        "height": 6
      },
      "maxSize": {
        "width": 6,
        "height": 24
      }
    },

The minSize and maxSize having the same width means that the panel can only resize in one dimension, between the extremes listed.
