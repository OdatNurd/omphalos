This would outline the basic concepts and terminology in Omphalos and
what they are.

* the [[manifest|guide.bundles#manifest]] is a `package.json` file for your bundle
* [[guide.graphics]] are graphical overlays that display in stream
* [[guide.panels]] are control panels that you use to control your stream
* [[guide.extensions]] are server side code that ties your extension together.
