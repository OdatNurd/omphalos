This would outline the basic concepts and terminology in Omphalos and
what they are.

* the [manifest](/guides/manifest) is a `package.json` file for your bundle
* [graphics](/guides/graphics) are graphical overlays that display in stream
* [panels](/guides/panels) are control panels that you use to control your stream
* [extensions](/guides/extensions) are server side code that ties your extension together.
