Each [[guide.graphics]] and [[guide.panels]] has a top level [[omphalos]]
object injected into it that represents the API that is available for them.

In addition, the [[manifest#extension|guide.extensions]]
[[main|guide.extensions#main]] function gets a parameter named [[omphalos]]
that similarly provides it with the API as well.
