Each [graphic](/guides/graphics) and [panel](/guides/panels) has a
top level `omphalos` object injected into it that represents the API
that is available for them.

In addition, the [extension](/guides/manifest/#extension)
[main](/guides/extensions/#main) function gets a parameter named `omphalos`
that similarly provides it with the API as well.
